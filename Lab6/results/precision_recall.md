# Precision / recall LLM-карти

| Показник | Значення |
|---|---:|
| Еталон (gold) | 45 тверджень |
| Унікальних триплетів LLM | 50 |
| TP | 40 |
| FP | 10 |
| FN | 5 |
| Precision | 0.800 |
| Recall | 0.889 |
| F1 | 0.842 |

## FP (помилкові твердження LLM)

- Подія на мережі — містить → Затримка
- GTFS-дані — містить → Диспетчер
- GTFS-дані — пов'язаний з → Transmodel (EN 12896)
- Інтелектуальна транспортна система — містить → Валідатор пасажирів
- NeTEx — містить → Час у дорозі
- Транспортна мережа — містить → Транспортна система
- Маршрут — спричиняє → Затримка
- Маршрут — містить → Затримка
- Розклад — містить → Пасажиропотік
- Зупинка — регламентується → Рейс

## FN (пропущені твердження еталону)

- Поїздка — містить → Рейс
- Інтелектуальне управління міською мобільністю — містить → Транспортна система
- Транспортна мережа — містить → Пересадочний вузол
- Маршрут — містить → Ділянка мережі
- Транспортна система — містить → Транспортна мережа
